# みてね2分カット

長い家族動画を、みてねに投稿しやすい2分以内の動画へ分割するWebアプリです。

動画はサーバーへ送信せず、ブラウザ内で処理します。元動画は変更せず、画質と撮影日時をできるだけ保ったまま、投稿しやすい長さに整えます。

## できること

- 2分を超える動画を、みてね向けの短い動画に分割します。
- 元動画を変更せず、新しい分割動画として保存します。
- 再エンコードを避け、画質劣化を抑えた分割を行います。
- 撮影日時を読み取り、分割後の動画にも時系列が残るようにします。
- 境界部分の欠けを避けるため、分割位置は少し重なる設計です。
- MP4、MOV、M4V形式の動画を対象にしています。

## 使い方

1. `動画を選ぶ` から、分割したい動画を選びます。
2. 動画の長さと分割計画を確認します。
3. `分割` を押すと、ブラウザ内で動画を分割します。
4. 完了後に `すべて保存` を押すと、作成された動画をまとめて保存します。
5. 保存された動画を、みてねへ順番に投稿します。

通常は、画面上部の濃い色のボタンを左から右へ押していけば進みます。選び直しや再分割が必要な場合は、薄い色のボタンから戻れます。

## 保存について

作成した動画は、保存するまでブラウザ内の一時データです。`すべて保存` を押すと、ブラウザまたは端末の既定のダウンロード先へ保存されます。

## プライバシー

動画処理は端末内で完結します。家族動画を外部サーバーへアップロードしない方針です。

## 注意点

- 長い動画や大きい動画では、端末の性能やブラウザのメモリにより処理時間が変わります。
- スマートフォンでは、保存後にみてねへ投稿する導線が端末やブラウザによって異なる場合があります。
- 撮影日時の保持は動画形式や端末のメタデータ仕様に影響されます。
