# みてね2分カット app

みてね2分カットのWebアプリ本体です。

このアプリは、長い家族動画をブラウザ内で分割し、みてねへ投稿しやすい2分以内の動画として保存できるようにします。

## 主な機能

- 動画を選ぶと、長さと分割計画を表示する。
- 2分を超えないように、内部では余裕を持った長さで分割する。
- 境界欠落を避けるため、分割位置を少し重ねる。
- 元動画は変更しない。
- 可能な限り再エンコードせず、画質劣化を抑える。
- 撮影日時を読み取り、分割開始位置に応じた日時を引き継ぐ。
- 作成した動画をまとめて保存できる。

## 利用の流れ

1. 動画を選ぶ。
2. 分割計画を確認する。
3. 分割する。
4. すべて保存する。
5. 保存した動画をみてねへ投稿する。

## プライバシー

動画処理はブラウザ内で行います。選択した動画を外部サーバーへ送信しない設計です。
